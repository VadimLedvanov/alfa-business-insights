# Frontend — Alfa Business Insights (Радар)

Интерфейс сервиса «Радар» внутри интернет-банка Альфа-Бизнес: показывает руководителю крупной компании,
что внешнее событие значит именно для его бизнеса — с учётом отрасли, продуктов банка и связей по платежам.

## Стек

- **React 18 + TypeScript + Vite**
- **@alfalab/core-components** 50.38.0 (корпоративная тема), **@alfalab/core-components-vars** 11.4.1 —
  настоящие токены и компоненты Альфа-Банка, поэтому оболочка выглядит как Альфа-Бизнес.
- **@alfalab/icons-glyph** 2.293.3 — иконки.

Все пакеты Альфы распространяются под лицензией **MIT** (внести в `THIRD_PARTY_NOTICES`).

## Запуск

```bash
npm ci
npm run dev      # дев-сервер на :3000, прокси /api и /auth на localhost:8080
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
```

В Docker собирается многоэтапно (Node → nginx), см. `Dockerfile`; внешний nginx проксирует `/` сюда,
а `/api` — на backend.

## Режимы данных

Переменная `VITE_API_MODE`:

- `stub` (по умолчанию) — данные из `src/api/stubs.ts`, прототип кликается без бэкенда;
- `live` — реальные запросы к `/api` (включать, когда готовы ручки).

Формы ответов в обоих режимах совпадают с DTO бэкенда (`src/api/types.ts`), поэтому переключение
режима не меняет экраны.

## Структура

- `src/api` — типы DTO, клиент (`client.ts`), демо-данные (`stubs.ts`).
- `src/components` — оболочка Альфа-Бизнеса (`AppShell`), карточки, плитки.
- `src/ui` — смысловой слой Радара: метки происхождения, бейджи влияния, уверенность словами, иконки, логотип.
- `src/pages` — экраны: вход, выбор компании, главная с виджетом, лента, разбор, источники (админ).
- `src/lib` — форматирование по правилам кейса (выручка 1000 → «нет данных», ВЭД со страной, термины),
  расчёт значимости, хуки загрузки.
